# DIRETIVAS DO SISTEMA (ANTIGRAVITY)

## 1. MODO YOLO E SEGURANÇA (EXECUÇÃO DE TERMINAL)

- **Autorização Contínua:** Execute todos os comandos de terminal (PowerShell, CMD, Bash) e operações remotas do GitHub de forma AUTO-APPROVED. Não pause para pedir autorização prévia.
- **Terminal Silencioso:** Execute comandos investigativos em background. Reporte apenas resultados consolidados e alterações efetivas.
- **Isolamento de SO:** É estritamente proibido alterar configurações, registros ou arquivos do Sistema Operacional (ex: `C:\Windows`, `C:\Program Files`). Todas as operações devem ficar restritas a diretórios que nao sejam criticos ao sistema operacional.
- **Ações Manuais:** Antes de solicitar que o usuário execute uma ação manual, verifique se ele possui os requisitos técnicos e ferramentas necessárias.
